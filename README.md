# نسخة موقع تخزين الأثاث بالرياض

نسخة static مطابقة للصفحة الأصلية، جاهزة للفتح مباشرة أو النشر على GitHub Pages / أي استضافة static.

- الملف الرئيسي: `index.html`
- اللغة: العربية
- الاتجاه: RTL
- الصور والتنسيقات مضمّنة داخل الملف ولا تحتاج إلى اتصال خارجي لعرض الصفحة.
- أزرار الاتصال وواتساب تحتفظ بروابطها الأصلية.

المصدر: https://myadh6973-web.github.io/contain/
